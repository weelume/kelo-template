# Kelo · AI 客户支持

独立中英双语响应式官网，包含原视频首屏、四项功能、三步流程、25 项集成、三档价格、分类 FAQ、更新列表/三篇文章、关于、联系及隐私/条款。共 14 页，默认中文、英文 /en。扩展内页和文章为原创演示内容。

Node 24.16.0、pnpm 9.15.4。准备：`pnpm install --frozen-lockfile`；开发 `pnpm dev`；检查 `pnpm typecheck`、`pnpm lint`、`pnpm test`；构建 `pnpm build`；生产 `pnpm start`。默认 http://127.0.0.1:43540，PORT 可修改；前台 Ctrl+C 停止。无需数据库、密钥或远程服务。正式安装与编译在本地 Linux 文件系统执行。

`pnpm bundle` 生成版本共享包；导出 template 和 host。品牌、内容、主题、组件与页面入口见 .tpl/customization.json。先读 .tpl/README.md、template.json、project.json。

演示表单只本地校验，不发送、不保存数据。原设计素材的商业再分发许可未完整确认；不得将公开访问等同商业授权。验收与差异见 .tpl/docs/VERIFICATION.md、MOTION.md。
